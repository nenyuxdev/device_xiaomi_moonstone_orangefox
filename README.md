# OrangeFox Recovery Device Tree for POCO X5 5G (moonstone)

This repository contains the device tree and configuration files required to build OrangeFox Recovery R12 for the Xiaomi POCO X5 5G (`moonstone`).

## Device Specifications

| Feature | Specification |
| :--- | :--- |
| **Device Name** | POCO X5 5G / Redmi Note 12 5G (India) |
| **Codename** | `moonstone` / `sunstone` |
| **SoC** | Qualcomm Snapdragon 695 5G (SM6375) |
| **Architecture** | 64-bit (ARM64) |
| **Storage / FBE** | UFS / File-Based Encryption (FBEv2) |
| **Partition Style** | Virtual A/B Partitions, Dynamic Partitions |
